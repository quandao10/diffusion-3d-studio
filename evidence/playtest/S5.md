## Observer notes

- **Intro / navigation.** S5 skipped the How-to-play text with Escape (00:05). The forbidden-word mechanic was learned later from the challenge card itself. "Just look around" opened the main menu, not the studio (01:07). A playwright text click on the menu cards failed because of the emoji labels, so the cards were clicked by position (tooling issue, not a game issue). Escape always toggled the menu, which is consistent.
- **Hesitation 1: forbidden word (04:01).** With "rocket" in the prompt, Generate was greyed out. The red explanation ("Challenge rule: you can't say 'rocket'.") sits below the fold, under the Guidance dropdown, so it was not visible while typing. It took about 40 s to find. The forbidden words are shown in red chips on the card, but there is no inline warning next to the prompt box.
- **Stop (05:46).** The confirm dialog appeared, then a clean "Stopped" modal. The job stopped at step 75/500 after 59 s. "Retry this target" kept the prompt and the target. Stale screens afterwards: the snapshot strip showed a broken image (alt text "training snapshot strip"), and the renderer kept the previous gallery model (pineapple). The card's round counter advanced to "round 2", but the server leaderboard later showed 1 round, so the stopped round was not counted server-side. There was also a mismatch: the header later said "0/1 wins" before any finished round.
- **Reload mid-generation (07:08).** Partial recovery. The running job was picked up and progress continued (step 125 at 07:14, finished normally). However, the Challenge card disappeared and the left panel fell back to Create mode with the default prompt "a small red mushroom house". The renderer showed the default owl. When the job finished, the preview verdict correctly referenced target "a rocket", so the challenge state survived underneath. A player might think the challenge was lost during the ~80 s until completion. No error messages.

Orbiting is possible only on that strip. Two of the three crown photos ended up nearly identical. The captured photos do not include the overlay.
