1. Plan vs. Reality

A2 MVP: one prompt → SDS from a frozen 2D diffusion model → optimise a NeRF → render novel views in an interactive viewer. Built: the same diffusion-guided loop running for real on an NVIDIA A100, but the 3D representation is explicit 3D Gaussians optimised with the official DreamGaussian code (commit 69a3c70), not a NeRF. Reason: a from-scratch SDS-NeRF needs long optimisation and much more debugging for a one-person project; DreamGaussian's rasterizer makes a 500-step run take ≈47 s, so I could iterate and build the studio, monitor and stress test around it. Upstream code is used unmodified (one build-fix include); my own work is the instrumentation wrapper, the WebGL2 splatting viewer, the studio server/UI, the benchmark and the capture pipeline.

3. AI Utility

  • Runtime AI (diffusion prior): works as planned: frozen SD 2.1-base supplies every gradient; no training of the diffusion model. The original stabilityai repo now returns HTTP 401, so I used a mirror of the same weights (documented).
  • Coding agent (Claude Code), listed in my tech spec: very useful for environment work and scaffolding. From the logs, the env build started 11:44 and the first successful 500-step run finished 12:04. It found and fixed: simple-knn missing <cfloat> (gcc 13); CUDA runtime headers only under targets/ on this server (CPATH); peak VRAM of 37 GB that turned out to be cudnn.benchmark switched on by the GUI seeding helper (fixed → 4.4 GB, the aborted log is kept); headless Chrome losing the WebGL context on Vulkan (switched to GL-EGL). It also wrote most of the wrapper, viewer, studio, benchmark and capture code.
  • Where it cost time: every result still had to be checked by looking at renders and logs. A blank viewer first looked like a shader bug but was a lost GPU context, and the browser landing on a busy GPU could not be fixed. Time savings are not measured against a baseline. The video voiceover is synthetic (Kokoro-82M TTS), and the on-screen captions match it.

4. Roadmap to Final

  • Geometry/consistency: try upstream MVDream/ImageDream multi-view guidance to reduce Janus faces; tune CFG/timestep schedule and negative prompts; run stage-2 mesh refinement (main2.py).
  • Studio: side-by-side seed/guidance comparison, run history with parameters, mesh/Gaussian toggle, websocket progress instead of polling.
  • Viewer performance: GPU sorting and level-of-detail for multi-million-Gaussian scenes; measure the browser viewer on a dedicated GPU.
  • Stretch (only after the above): VSD comparison, as described in A2.
