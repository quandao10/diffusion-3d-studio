6 What is running

  1. Text prompt yencoded once by the frozen SD-2.1-base text encoder
  2. 3D Gaussians θ5k random blob → positions, scales, rotations, opacity, colour
  3. Random camera celevation ±30°, full azimuth, radius 2.5
  4. Differentiable rasterizerCUDA tile splatting, x = g(θ, c), 128→512 px
  5. SDSadd noise at annealed t, UNet predicts ε̂ (CFG 100), ∇θ = w(t)(ε̂ − ε)·∂x/∂θ
  6. Adam + densify/prune500 steps; then save PLY, extract textured mesh

Plan vs. reality: Assignment 2 planned an SDS-guided NeRF (volume rendering). This MVP keeps the same diffusion-guided loop but optimises explicit 3D Gaussians with the official DreamGaussian code (Tang et al., ICLR 2024) for speed and feasibility. VSD and TRELLIS are not implemented.
